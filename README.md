# BOLT 2 // КИБЕР-АЛМАТЫ

Браузерный **3D-экшен / шутер от первого лица** в **полуоткрытом мире Кибер-Алматы (500×500 м)** на **TypeScript + Vite + Three.js** с потоковой **системой чанков (`10×10` чанков по 50×50 м)** — прямое продолжение приквела [BOLT // MARAKULIN TOWER: 2026](https://github.com/DySh-1789/Bolt).

## О мире и сюжете

Главный герой — наёмник **Аи (Амир)**, в голове которого после провального ограбления в **Маракулин Тауэр** и гибели лучшего друга **Санжара** активируется биочип с цифровым конструктом **Самира** (героя первой части *Bolt*).

### Полная кампания (10 актов) + Свободный режим Кибер-Алматы
1. **Пролог — Крыша Кок-Тобе**: Аи и Самир смотрят на ночной Маракулин Тауэр (*«Ты, я и Маракуя Тауэр...»*).
2. **2 недели назад — Пентхаус Маракулин Тауэр**: кража биочипа с Санжаром, прятки в шкафу, убийство Льва Маракулина Родионом при Рихарде Смэшере и побег с боем на лифте.
3. **Погоня в такси «Кибер-Ахмед»**: отстрел корпо-дронов на скоростной трассе, трагическая гибель Санжара и установка биочипа.
4. **Мотель на Кибер-Тастаке**: встреча с Артёмом, засада телохранителя, бой **Клинками Богомола** и выстрел Артёма в голову.
5. **Свалка — Пробуждение**: Аи приходит в себя рядом с трупом Артёма и впервые встречает голографического Самира.
6. **Полуоткрытый мир Кибер-Алматы (500×500 м)**:
   - **5 районов**: Кибер-Тастак, Проспект Абая / Ебланхана (**Антикафе «Марум»** с Рипердоком), Свалка, Площадь Маракулин Тауэр, Нижний квартал и Смотровая крыша Кок-Тобе на фоне гор **Заилийского Алатау** и телебашни **Кок-Тобе**.
   - **Система чанков (`ChunkManager`)**: сетка 10×10 чанков по 50×50 м с динамической активацией видимости, коллизий и источников света + постоянный слой дальних ориентиров.
   - **Управляемое такси «Кибер-Ахмед»**: ручное вождение (1-е / 3-е лицо, дрифт, нитро), вызов клавишей `C`, встроенный **Автопилот (`G`)** и быстрое перемещение через карту (`M`).
   - **5 побочных заказов Ебланханы** (включая поиск легендарного **Malorian S-3516** Самира и охоту на киберпсиха).
7. **Штурм Маракулин Тауэр**: прорыв через парадный вход (*«Пора развлечься как в 2026»*) и спуск на лифте к подземному комплексу **«Хуеши»**.
8. **Финальный босс — Рихард Смэшер**: 3-фазный бой с автопушкой, микроракетами, Sandevistan-рывками и ударными волнами + **интерактивное добивание из Malorian S-3516**.
9. **«Хуеши» и Киберпространство**: встреча с **Таисией** и выбор судьбы.
10. **Две полноценные концовки**:
    - **Легенда Ебланханы**: Аи возвращается в своё тело на полгода, становится владельцем антикафе **«Марум»** и принимает контракт **Егора** на Вечную войну.
    - **Дорога в Талдыкорган**: Аи отдаёт тело Самиру, и Самир уезжает из Кибер-Алматы в город-ад **Талдыкорган**.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` | Передвижение / Вождение «Кибер-Ахмеда» |
| `Мышь` | Обзор (Pointer Lock) |
| `ЛКМ` / `ПКМ` | Огонь (Комбо Клинков) / Прицел (Рывок-выпад Клинками) |
| `1–5` / `Колесо` | Клинки Богомола, Алатау-19, Степь-9 ПП, Буран-12, Malorian S-3516 |
| `R` / `F` | Перезарядка / Огненный ближний удар Malorian |
| `Space` (×2) | Прыжок / Двойной прыжок / Ручник (дрифт в такси) |
| `Shift` / `Q` / `X` | Рывок (Нитро в такси) / Сандевистан / MaxDoc |
| `E` | Взаимодействие / Сесть-выйти из такси / Рипердок / Добивание |
| `C` / `G` / `V` | Вызвать «Кибер-Ахмеда» / Автопилот / Камера 1-е ↔ 3-е лицо |
| `M` / `Tab` | Карта Кибер-Алматы, заказы и быстрое перемещение |
| `Esc` | Пауза и настройки (чувствительность, громкость, цензура диалогов) |
